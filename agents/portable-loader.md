# Portable runtime entry point

Load the repository root `SKILL.md` as the canonical instructions for `skill-stock-score`.

The skill accepts an A-share stock code or an industry/sector name. It requires `skill-pandadata-api` for live data. Keep source dates, missing-data disclosures, assumptions, and risk warnings in every report. The output is research-only and must not be presented as investment advice or a return guarantee.
