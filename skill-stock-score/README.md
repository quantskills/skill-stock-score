# skill-stock-score

`skill-stock-score` 是一个面向 A 股研究的五维基本面评分 Skill。它根据财务状况、消息面、行业前景、债务与偿债能力、股东增减持与资本运作五个维度计算 100 分制评分，并支持按行业输出 TOP10 排名。

## 用途

- 输入 6 位 A 股代码或带交易所后缀的代码，生成个股评分报告。
- 输入行业或板块名称，生成板块内基本面评分排序。
- 结果应同时列出数据日期、数据来源、缺失字段和风险提示。

## 运行要求

- 需要可用的 `skill-pandadata-api` 数据能力。
- 支持 Codex、Claude Code、Cursor、Hermes 和 OpenClaw 的入口见 `SKILL.md` 与 `agents/`。
