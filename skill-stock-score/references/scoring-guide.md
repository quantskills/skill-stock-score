# 五维基本面评分详细指引

本文档提供 SKILL.md 中评分规则的详细计算逻辑、阈值和示例，供评分时逐条查阅。

---

## 维度一：财务状况（30分）详细规则

### 数据获取

通过 `get_fina_reports(ts_code, report_type="1")` 获取利润表数据（revenue、net_profit等）。
- 取最近3个完整会计年度的年报数据（`end_type=4` 代表年报）
- 或最近3个可获取的季度/半年报数据（如新股可用最近3个季度数据）
- 通过 `fina_ann_dt` 字段排序取最新的3期

### 1.1 净利润趋势（10分）

**数据准备：** 提取最近3期净利润（net_profit）数据，分别记为 P1（最旧）、P2（中间）、P3（最新）。

**评分标准：**

| 条件 | 得分 | 说明 |
|------|------|------|
| P3 > P2 > P1，且全部为正 | 10 | 利润持续增长 |
| P3 > P2 > P1，P1为负，P3为正 | 8 | 快速扭亏且增长 |
| P3 > P2 但 P1 > P2（V型反转） | 7 | 触底反弹 |
| P2 > P3 > P1（最新略有回落） | 6 | 高位微调 |
| P3 > P1 > P2（波动上升） | 6 | 波动向上 |
| P3 = P2 ≈ P1（持平） | 5 | 稳定无增长 |
| P3 < P2 但 P3 > P1（小幅回落） | 4 | 利润回撤 |
| P3 < P2 < P1，P3仍为正 | 3 | 持续下滑中 |
| P2 > P3 且 P3为负 | 1 | 最新一期亏损 |
| P1、P2、P3均为负 | 0 | 持续亏损且恶化 |

### 1.2 盈利模式判定（8分）

基于最近2期净利润符号：

| 模式 | 判定条件 | 得分 | 信号含义 |
|------|----------|------|----------|
| 持续盈利 | P1 > 0 且 P3 > 0，且同比增长>0 | 8 | 经营稳健 |
| 扭亏为盈 | P1 <= 0 且 P3 > 0 | 6 | 经营改善 |
| 波动盈利 | (P1 > 0 且 P3 > 0 但同比增长<0) 或 (P2!=P1且P2!=P3) | 4 | 盈利不稳定 |
| 持续亏损 | P1 <= 0 且 P3 <= 0 | 1 | 经营困难 |
| 由盈转亏 | P1 > 0 且 P3 <= 0 | 0 | 恶化预警 ⚠️ |

### 1.3 营收增速（6分）

计算营业收入同比增长率（3期平均或在最新期数据上计算）：

```
营收增长率 = (最新期营收 - 上年同期营收) / 上年同期营收 × 100%
```

| 条件 | 得分 | 说明 |
|------|------|------|
| 增长率 > 30% | 6 | 高速增长 |
| 增长率 15%-30% | 5 | 快速增长 |
| 增长率 5%-15% | 4 | 稳定增长 |
| 增长率 0%-5% | 3 | 低速增长 |
| 增长率 -10% - 0% | 2 | 轻微下滑 |
| 增长率 -30% - -10% | 1 | 明显下滑 |
| 增长率 < -30% | 0 | 大幅下滑 |

### 1.4 毛利率/净利率水平（6分）

**计算方法：**
- 毛利率 = 1 - (营业成本/营收) — 从利润表提取 `cost` 和 `revenue`
- 净利率 = 净利润/营收 — 从利润表提取 `net_profit` 和 `revenue`

**评分标准（毛利率）：**

| 条件 | 得分 |
|------|------|
| 毛利率 > 50%（高毛利，如白酒/医药） | 6 |
| 毛利率 30%-50%（中高毛利） | 5 |
| 毛利率 20%-30%（中等毛利） | 4 |
| 毛利率 10%-20%（低毛利） | 3 |
| 毛利率 5%-10%（微利行业） | 2 |
| 毛利率 < 5% | 1 |
| 毛利率为负 | 0 |

**修正规则：** 若净利率为负，在毛利率得分基础上扣2分（最低0分）。

### 1.5 行业比较加分/扣分

若 `get_stock_industry_median`（港股）或同类行业中位数数据可用：
- 毛利率高于行业中位数10%以上：额外+1分
- 毛利率低于行业中位数10%以上：额外-1分

## 维度二：消息面（20分）详细规则

### 数据获取

```python
# 并行获取
get_fina_forecast(ts_code)                    # 业绩预告
get_investor_activity(ts_code)                # 投资者关系/调研
get_stock_recommendation_consensus(ts_code)   # 研报评级
```

### 2.1 业绩预告评分（6分）

解析 `get_fina_forecast` 的 `forecast_content` 字段：

| 预告类型关键词 | 得分 | 说明 |
|---------------|------|------|
| 预增/大幅上升/扭亏 | 6 | 业绩超预期 |
| 略增/小幅上升 | 5 | 业绩向好 |
| 续盈/持平 | 3 | 符合预期 |
| 略减/小幅下降 | 2 | 业绩承压 |
| 预减/大幅下降/预亏/首亏 | 0 | 业绩爆雷 |
| 不确定/无数据 | 3 | 中性处理 |

注意：若 `get_fina_forecast` 无数据或最新业绩期已过（已披露正式财报），此项按3分处理（不扣分不扣分）。

### 2.2 机构调研活跃度（4分）

解析 `get_investor_activity` 返回数据，取最近3个月的数据：

| 条件 | 得分 |
|------|------|
| 近3个月有>2次调研，且每次>20家机构参与 | 4 |
| 近3个月有1-2次调研，单次>10家机构 | 3 |
| 近3个月有1次调研或参与机构较少 | 2 |
| 近6个月无机构调研 | 1 |
| 无数据 | 2 |

额外加分：知名机构（高瓴/景林/睿远/易方达等头部公募私募）参与 → +1分封顶

### 2.3 重大事件情绪分析（6分）

参考最近3个月的重大事件，包括：
- 从 `get_stock_market_event` 获取的市场相关事件（如有覆盖A股）
- 从 `get_stock_financial_event` 获取的财务相关事件
- 其他公开可获取的公司公告信息

**事件分类与分值：**

| 事件类型 | 分值 | 示例 |
|----------|------|------|
| 🟢 **重大利好** | +6 | 重大资产重组获批、大额订单/合同（>上年营收50%）、核心产品获批上市、退市风险解除、获得国家战略扶持 |
| 🔵 **一般利好** | +3 | 中标重要项目、获得专利授权、签署战略合作协议、子公司分拆上市计划、核心产品进入医保/集采中标 |
| ⚪ **中性** | 0 | 高管人事变动、常规分红预案、工商变更、对外投资（金额不大） |
| 🟠 **一般利空** | -3 | 收到监管问询函、涉及诉讼（金额不大）、股东减持计划、业绩预告低于预期 |
| 🔴 **重大利空** | -6 | 被证监会立案调查、业绩预告变脸（预增变预亏）、债务违约、资产被冻结、实控人失联、退市风险警示 |

**算法：** 将所有事件分值累加（正负相抵），最终映射到0-6分：
- 累计 >= +6 → 6分（极度利好）
- 累计 +3 ~ +5 → 5分（明显利好）
- 累计 0 ~ +2 → 4分（偏利好）
- 累计 -1 ~ +1 → 3分（中性偏正面）
- 累计 -2 ~ 0 → 3分（中性）
- 累计 -5 ~ -3 → 2分（偏利空）
- 累计 -6 ~ -5 → 1分（明显利空）
- 累计 < -6 → 0分（重大利空）

### 2.4 卖方研报评级（4分）

解析 `get_stock_recommendation_consensus` 返回的近期研报数据：

| 条件 | 得分 |
|------|------|
| 近3个月>=2家券商给予"买入"评级 | 4 |
| 近3个月1家"买入"或>=2家"增持" | 3 |
| 近3个月有"中性"评级 | 2 |
| 近3个月有"减持"或"卖出"评级 | 0 |
| 无研报覆盖 | 1 |

额外加分：若有头部券商（中金/中信/华泰/国泰君安等TOP10券商）在近1个月内首次覆盖并给予买入 → +1分封顶

## 维度三：行业前景（20分）详细规则

### 数据获取

```python
get_stock_industry(ts_code)              # 获取行业代码
get_industry_detail(industry_code)       # 获取行业详情
get_index_daily(index_code)              # 行业指数走势
get_index_indicator(index_code)          # 行业估值指标
# 宏观数据（根据行业类别选择）
get_macro_in()  # 工业 - 工业增加值
get_macro_pm()  # PMI
get_macro_sm()  # 证券市场数据
```

### 3.1 行业景气度（8分）

**行业周期分类判断：**

| 行业类型 | 特征 | 示例 |
|----------|------|------|
| 成长型行业 | 营收增速>15%，政策鼓励 | 新能源、半导体、AI、生物医药 |
| 周期型行业 | 与宏观经济高度相关 | 钢铁、有色、化工、煤炭 |
| 成熟型行业 | 增速平稳，格局稳定 | 银行、家电、食品饮料 |
| 衰退型行业 | 增速为负，需求萎缩 | 传统纸媒、部分传统制造 |

**景气度判定依据：**
1. 行业指数近3月涨跌幅（参考 `get_index_daily`）
2. 行业营收增长率中位数（通过成分股财务数据推断）
3. 宏观指标匹配：制造业看PMI，消费看社零，出口看出口数据

| 景气度判断 | 得分 |
|-----------|------|
| 高景气（行业指数3月涨>15%，且需求旺盛） | 8 |
| 较高景气（行业指数3月涨5%-15%，且趋势向好） | 7 |
| 平稳向上（行业指数3月涨0%-5%，或微涨） | 6 |
| 平稳（指数横盘震荡） | 5 |
| 平稳偏弱（指数3月跌0%-5%） | 4 |
| 景气下行（指数3月跌5%-15%） | 3 |
| 不景气（指数3月跌>15%） | 1-2 |
| 行业处于明显下行周期或衰退 | 0-1 |

### 3.2 行业估值水位（6分）

参考 `get_index_indicator` 获取行业指数PE/PB数据：

| PE/PB历史分位数（近5年） | 得分 |
|--------------------------|------|
| < 20%（低估区间） | 6 |
| 20%-40%（偏低区间） | 5 |
| 40%-60%（合理区间） | 4 |
| 60%-80%（偏高区间） | 3 |
| 80%-95%（高估区间） | 2 |
| > 95%（极度高估） | 1 |

**修正规则：** 成长型行业可容忍更高估值，在高分位时仅扣1分；周期型行业在低估区间可额外+1分（利好布局）

### 3.3 行业监管/政策环境（3分）

| 政策环境 | 得分 | 示例 |
|----------|------|------|
| 强鼓励（国家战略/补贴/税收优惠） | 3 | 新能源、半导体、芯片、AI |
| 中性支持（政策友好，适度监管） | 2 | 消费、医药（集采缓和后） |
| 中性 | 1.5 | 大多数传统行业 |
| 加强监管/紧缩政策 | 1 | 房地产（三道红线）、教培（双减政策）、互联网平台反垄断 |
| 严格限制/打击 | 0 | 被政策明确打压的行业 |

### 3.4 行业竞争格局（3分）

| 竞争格局 | 得分 | 判定依据 |
|----------|------|----------|
| 寡头垄断（CR5>60%） | 3 | 龙头地位稳固，盈利能力强 |
| 龙头集中（CR5 40%-60%） | 2.5 | 有一定龙头溢价 |
| 充分竞争（CR5 20%-40%） | 2 | 竞争激烈，利润较薄 |
| 极度分散（CR5<20%） | 1.5 | 进入壁垒低，价格战 |
| 新兴行业格局未定 | 1 | 不确定性大，但可能有爆发机会 |

注：CR5参考成分股数据，可通过行业中位数和成分股权重分布判断集中度。

## 维度四：债务偿债分析（15分）详细规则

### 数据获取

```python
get_fina_reports(ts_code, report_type="1")    # 资产负债表(bs)数据
get_stock_pledge_stat(ts_code)                # 质押统计
# 从利润表中获取利息支出：get_fina_reports(ts_code, report_type="1")
```

### 4.1 资产负债率（5分）

```
资产负债率 = 总负债（total_liabilities） / 总资产（total_assets）
```

| 资产负债率 | 得分 | 说明 |
|-----------|------|------|
| < 30% | 5 | 财务非常稳健，但可能保守 |
| 30%-45% | 4 | 健康的负债水平 |
| 45%-60% | 3 | 行业平均水平（参考行业中位数） |
| 60%-70% | 2 | 偏高，需关注 |
| 70%-85% | 1 | 高负债，风险较大 |
| > 85% | 0 | 极高负债，接近资不抵债 |

**行业调整：** 金融、地产等行业资产负债率天然偏高，评分时将行业中位数作为基准：
- 低于行业中位10%以上：+1分
- 高于行业中位10%以上：-1分
- 高于行业中位30%以上：额外再-1分

### 4.2 流动比率与速动比率（4分）

```
流动比率 = 流动资产（total_current_assets） / 流动负债（total_current_liabilities）
速动比率 = （流动资产 - 存货（inventory）） / 流动负债（total_current_liabilities）
```

| 流动比率 | 速动比率 | 得分 |
|----------|----------|------|
| > 2.0 | > 1.0 | 4 |
| 1.5-2.0 | 0.8-1.0 | 3 |
| 1.0-1.5 | 0.5-0.8 | 2 |
| 0.5-1.0 | 0.2-0.5 | 1 |
| < 0.5 | < 0.2 | 0 |

注：若无速动比率数据，仅使用流动比率，得分上限3分。

### 4.3 股权质押比例（3分）

解析 `get_stock_pledge_stat` 返回的质押比例（pledge_ratio）：

| 质押比例 | 得分 | 含义 |
|----------|------|------|
| < 10%（或无质押） | 3 | 基本无质押风险 |
| 10%-30% | 2 | 中等质押比例 |
| 30%-50% | 1 | 质押比例较高，存在平仓风险 |
| > 50% | 0 | 极高质押，大比例质押风险极大 |

**预警标记：** 质押比例>30%且股价接近质押平仓线 → 自动在风险提示中标记 🔴

### 4.4 有息负债率（3分）

```
有息负债率 = (短期借款 + 长期借款 + 应付债券) / 总资产
```

从利润表中提取 `st_borrow`（短期借款）、`lt_borrow`（长期借款，可能为non_current_liabilities的子类）。

| 有息负债率 | 得分 |
|-----------|------|
| < 10% | 3 |
| 10%-20% | 2.5 |
| 20%-30% | 2 |
| 30%-40% | 1.5 |
| 40%-50% | 1 |
| > 50% | 0 |

**利息保障倍数（辅助参考，不计入权重，只做提示）：**
```
利息保障倍数 = EBIT / 利息费用 ≈ (净利润 + 所得税 + 利息费用) / 利息费用
```
- 利息保障倍数 < 1：企业利润不足以支付利息 → 风险提示
- 利息保障倍数 < 0：企业亏损，偿债能力极弱 → 风险提示

## 维度五：增减持与资本运作（15分）详细规则

### 数据获取

```python
get_stock_shareholder_change(ts_code)     # 股东增减持计划
get_repurchase(ts_code)                   # 回购数据
get_restricted_list(ts_code)              # 限售解禁数据
```

### 5.1 大股东增减持（6分）

解析 `get_stock_shareholder_change` 返回的 `plan_type`（计划类型）、`plan_status`（计划状态）、`plan_volume`（计划数量）：

**股东增减持计划分析：**

| 场景 | 得分 | 判定逻辑 |
|------|------|----------|
| 大股东大幅增持（计划增持>0.5%总股本）且已完成 | 6 | 强烈信心信号 |
| 大股东/公司增持计划实施中 | 5 | 正面信号 |
| 大股东小幅增持或高管集体增持 | 4 | 积极信号 |
| 无增减持计划 | 3 | 中性 |
| 有大股东/董监高减持计划但未开始执行 | 2 | 偏负面 |
| 有减持计划且正在执行 | 1 | 负面信号 |
| 大股东大比例减持（>1%总股本）或清仓式减持 | 0 | 极度负面信号 |

**多个计划处理：**
- 同时存在增持和减持计划 → 按净额判断（增持总额 - 减持总额）
- 仅看已完成/执行中的计划，已过期/已终止的计划不计入

### 5.2 高管增减持（3分）

通过 `get_stock_shareholder_change` 的 `holder_type` 筛选高管相关数据，或使用A股内部人交易数据接口：

| 场景 | 得分 |
|------|------|
| 高管集体增持（>=3位高管近3个月增持） | 3 |
| 个别高管增持 | 2 |
| 无高管增减持 | 2 |
| 个别高管减持 | 1 |
| 高管集体减持（>=3位高管近3个月减持） | 0 |

### 5.3 回购计划（3分）

解析 `get_repurchase` 返回数据：

| 回购类型 | 得分 | 说明 |
|----------|------|------|
| 已完成回购，金额较大（>5亿元或>流通市值1%） | 3 | 强力信心 |
| 回购实施中，金额适中 | 3 | 积极信号 |
| 已完成回购，金额较小 | 2 | 轻度积极 |
| 有回购预案尚未实施 | 2 | 预期积极 |
| 无回购计划 | 1.5 | 中性 |
| 同时存在减持计划与回购 | 0 | 可能是配合减持的虚假回购 ⚠️ |

### 5.4 限售解禁压力（3分）

解析 `get_restricted_list` 返回的未来解禁数据：

| 解禁类型 | 得分 | 条件 |
|----------|------|------|
| 未来12个月无解禁 | 3 | 无解禁压力 |
| 未来6-12个月有解禁，单次<1%总股本 | 3 | 压力很小 |
| 未来3-6个月有解禁，合计<3%总股本 | 2.5 | 轻微压力 |
| 未来1-3个月有解禁，合计<5%总股本 | 2 | 需关注 |
| 未来3-6个月有大额解禁（>5%总股本） | 1 | 压力明显 |
| 未来1个月内有解禁，且>5%总股本 | 0 | 短期巨量解禁，注意抛压 ⚠️ |

## 总分计算与等级

### 加权合并

```
总分 = 财务状况得分 + 消息面得分 + 行业前景得分 + 债务偿债得分 + 增减持得分
```

### 等级划分

| 总分范围 | 等级 | 标签 | 投资含义 |
|----------|------|------|----------|

### 特殊标记

- ⭐ **亮点**：单个维度得分率达到90%以上（如财务状况27/30以上）
- ⚠️ **关注**：单个维度得分率低于30%
- 🔴 **风险**：维度五得分低于5分（增减持出现重大问题）
- 🚨 **警报**：财务状况为"由盈转亏"或消息面得分<5分

## 行业TOP10排序特殊规则

### 评分简化处理

对行业所有成分股进行批量评分时，以下维度可以复用：

1. **行业前景（维度三）**：同行业所有股票使用相同的行业评分 → 只评一次，全部复用
2. **消息面（维度二）**：业绩预告逐股评，但行业级别事件可通用（如行业政策利好对所有成分股加分）
3. **其他维度**（财务、债务、增减持）：逐股独立评分

### 排序与去重

- 按总分降序排列
- 若总分相同，按财务状况得分降序排列（财务维度权重最高）
- 若仍相同，按市值从大到小排列
- 剔除ST/*ST股票，自动标记但不参与排名

### 成分股过多（>100只）的处理

- 按流通市值排序，取前50只作为评分样本
- 在报告中标注：`*基于流通市值TOP50成分股评分`

## 审计意见处理

若 `get_audit_opinion` 返回非标意见（保留意见/否定意见/无法表示意见）：

| 审计意见 | 处理 |
|----------|------|
| 标准无保留意见 | 正常评分 |
| 带强调事项段的无保留意见 | 总分扣5分 |
| 保留意见 | 总分扣15分 |
| 否定意见/无法表示意见 | 直接判定为 C 级（最高39分） |
